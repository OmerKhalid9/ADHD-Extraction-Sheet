# ADHD Literature Review

This sheet accompanies a systematic literature review of machine learning (ML) and deep learning (DL) approaches for ADHD (Attention-Deficit/Hyperactivity Disorder) detection, classification, and related research - 201 papers in total.

## File

- **`201_ADHD_Papers_PICOS.csv`** - A PICOS-framework summary of the same 201 papers (Population, Intervention/Index test, Comparison, Outcome, Study design) - 201 rows × 10 columns.

## `201_ADHD_Papers_PICOS.csv` - Column Reference

| Column | Description |
|---|---|
| SR NO | Row number within this file (1–201) |
| Authors | Author list as cited |
| Title | Paper title |
| Year | Publication year |
| Sample Size | Number of participants/subjects in the study |
| Child/Adult | Population studied |
| Data Modality | Data type used (EEG, rs-fMRI, clinical data, activity data, etc.) |
| ML/DL Algorithm | Algorithm(s) evaluated |
| Comparison | Groups compared (e.g. ADHD vs. Control, ADHD-I vs. ADHD-C) |
| Outcome | Reported result metric(s) |

## Conventions

- A dash (`-`) means the source paper didn't report that information. It reflects an absence in the original source, not a data-entry gap.
